在飞书开放平台中，筛选字段时可使用以下关系运算符，适用于多维表格、视图筛选等多种场景：

### 支持的运算符及说明
1. **等于（is）**  
   - 匹配字段值与指定值完全相等  
   - 适用于所有字段类型，如文本、数字、单选等  

2. **不等于（isNot）**  
   - 匹配字段值与指定值不相等  
   - **注意**：不支持日期字段  

3. **包含（contains）**  
   - 匹配字段值包含指定内容  
   - 适用于文本、多选等字段类型，**不支持日期字段**  

4. **不包含（doesNotContain）**  
   - 匹配字段值不包含指定内容  
   - 适用于文本、多选等字段类型，**不支持日期字段**  

5. **为空（isEmpty）**  
   - 匹配字段值为空的记录  
   - 所有字段类型均支持，此时 `value` 参数需设为空数组 `[]`  

6. **不为空（isNotEmpty）**  
   - 匹配字段值不为空的记录  
   - 所有字段类型均支持，此时 `value` 参数需设为空数组 `[]`  


### 使用示例场景
#### 1. 多维表格记录筛选（查询记录接口）
通过 `filter` 参数设置条件，例如筛选"职位"字段包含"销售"且"销售额"不等于 0 的记录：  
```json
{
  "filter": {
    "conjunction": "and",
    "conditions": [
      {
        "field_name": "职位",
        "operator": "contains",
        "value": ["销售"]
      },
      {
        "field_name": "销售额",
        "operator": "isNot",
        "value": ["0"]
      }
    ]
  }
}
```
详情参考 [记录筛选参数填写说明](https://go.feishu.cn/s/6lY28723E04)。

#### 2. 视图筛选条件配置（更新视图接口）
设置视图筛选条件，例如筛选"状态"字段等于"进行中"且"截止日期"不为空的记录：  
```json
{
  "property": {
    "filter_info": {
      "conjunction": "and",
      "conditions": [
        {
          "field_id": "fldStatus",
          "operator": "is",
          "value": "[\"进行中\"]"
        },
        {
          "field_id": "fldDeadline",
          "operator": "isNotEmpty",
          "value": "[]"
        }
      ]
    }
  }
}
```
详情参考 [更新视图](https://go.feishu.cn/s/6es8QK8xU03)。

#### 3. 自定义角色权限配置（新增/更新自定义角色接口）
在高级权限中限制记录访问范围，例如仅允许查看"创建人"包含当前用户且"部门"不为空的记录：  
```json
{
  "table_roles": [
    {
      "table_perm": 1,
      "rec_rule": {
        "conditions": [
          {
            "field_name": "创建人",
            "operator": "contains",
            "value": ["当前用户ID"]
          },
          {
            "field_name": "部门",
            "operator": "isNotEmpty",
            "value": []
          }
        ],
        "conjunction": "and",
        "perm": 1
      }
    }
  ]
}
```
详情参考 [新增自定义角色](https://go.feishu.cn/s/6uRLNc5mE04)。


### 注意事项
- **字段类型限制**：日期字段不支持 `isNot`、`contains`、`doesNotContain` 运算符。  
- **value 参数格式**：  
  - `isEmpty`/`isNotEmpty` 需传入空数组 `[]`；  
  - 文本/数字类型值需用字符串格式，如 `["100"]`；  
  - 多选/单选字段需传入选项 ID 或名称，具体参考 [字段目标值填写说明](https://go.feishu.cn/s/6lY28723E04#3e0fd644)。  
- **多条件逻辑**：通过 `conjunction` 参数设置 "and"（与）或 "or"（或）关系。  

根据具体业务场景，选择合适的运算符组合即可实现精准筛选。
