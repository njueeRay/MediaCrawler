# 配置系统与命令行接口

## 1. 配置体系概览

MediaCrawler 的配置分为三层：

```
┌─────────────────────────────────────┐
│      命令行参数 (最高优先级)          │  cmd_arg/arg.py (Typer CLI)
├─────────────────────────────────────┤
│      全局配置文件                     │  config/base_config.py
│      ├── 平台配置 (xhs_config 等)    │  config/<platform>_config.py
│      └── 数据库配置                  │  config/db_config.py
├─────────────────────────────────────┤
│      环境变量 (最低优先级)            │  .env 文件 + os.getenv()
└─────────────────────────────────────┘
```

优先级：**CLI 参数 > config 模块全局变量 > 环境变量**

## 2. 全局配置 (`config/base_config.py`)

### 2.1 基础配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `PLATFORM` | str | `"xhs"` | 目标平台：xhs/dy/ks/bili/wb/tieba/zhihu |
| `KEYWORDS` | str | - | 搜索关键词，英文逗号分隔 |
| `LOGIN_TYPE` | str | `"qrcode"` | 登录方式：qrcode/phone/cookie |
| `COOKIES` | str | `""` | Cookie 登录时的 Cookie 值 |
| `CRAWLER_TYPE` | str | `"search"` | 爬取类型：search/detail/creator |
| `SAVE_DATA_OPTION` | str | `"csv"` | 存储方式：csv/db/json/sqlite/mongodb/excel/postgres |

### 2.2 浏览器配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `HEADLESS` | bool | `False` | 标准模式下是否无头 |
| `ENABLE_CDP_MODE` | bool | `True` | 是否启用 CDP 模式 |
| `CDP_DEBUG_PORT` | int | `9222` | CDP 调试端口 |
| `CUSTOM_BROWSER_PATH` | str | `""` | 自定义浏览器路径 |
| `CDP_HEADLESS` | bool | `False` | CDP 模式下是否无头 |
| `BROWSER_LAUNCH_TIMEOUT` | int | `60` | 浏览器启动超时（秒） |
| `AUTO_CLOSE_BROWSER` | bool | `True` | 程序结束时关闭浏览器 |
| `SAVE_LOGIN_STATE` | bool | `True` | 是否保存登录状态 |
| `USER_DATA_DIR` | str | `"%s_user_data_dir"` | 浏览器用户数据目录模板 |

### 2.3 代理配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ENABLE_IP_PROXY` | bool | `False` | 是否启用 IP 代理 |
| `IP_PROXY_POOL_COUNT` | int | `2` | 代理 IP 池数量 |
| `IP_PROXY_PROVIDER_NAME` | str | `"kuaidaili"` | 代理提供商：kuaidaili/wandouhttp |

### 2.4 爬取控制

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `START_PAGE` | int | `1` | 起始页码 |
| `CRAWLER_MAX_NOTES_COUNT` | int | `100` | 最大爬取帖子数 |
| `MAX_CONCURRENCY_NUM` | int | `1` | 并发爬虫数 |
| `CRAWLER_MAX_SLEEP_SEC` | int | `2` | 请求间隔（秒） |
| `ENABLE_GET_COMMENTS` | bool | `False` | 是否爬取评论 |
| `ENABLE_GET_SUB_COMMENTS` | bool | `False` | 是否爬取二级评论 |
| `CRAWLER_MAX_COMMENTS_COUNT_SINGLENOTES` | int | `10` | 单帖最大评论数 |
| `ENABLE_GET_MEIDAS` | bool | `True` | 是否下载媒体资源 |

### 2.5 词云配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ENABLE_GET_WORDCLOUD` | bool | `False` | 是否生成词云 |
| `CUSTOM_WORDS` | dict | `{...}` | 自定义词语及分组 |
| `STOP_WORDS_FILE` | str | `"./docs/hit_stopwords.txt"` | 停用词文件 |
| `FONT_PATH` | str | `"./docs/STZHONGS.TTF"` | 中文字体文件 |

### 2.6 配置加载机制

`base_config.py` 末尾通过 `from .xxx_config import *` 导入各平台配置：

```python
# config/base_config.py 末尾
from .bilibili_config import *
from .xhs_config import *
from .dy_config import *
from .ks_config import *
from .weibo_config import *
from .tieba_config import *
from .zhihu_config import *
```

其他模块通过 `import config` 即可访问所有配置：
```python
import config
print(config.PLATFORM)          # 全局配置
print(config.SORT_TYPE)         # 小红书配置（来自 xhs_config.py）
print(config.DY_SPECIFIED_ID_LIST)  # 抖音配置（来自 dy_config.py）
```

## 3. 平台特有配置

### 3.1 小红书 (`config/xhs_config.py`)

```python
SORT_TYPE = "popularity_descending"       # 排序方式
XHS_ENABLE_TIME_RANGE = False             # 是否启用时间范围筛选
START_DAY = "2026-01-01"                  # 开始日期
END_DAY = "2026-01-20"                    # 结束日期
XHS_SPECIFIED_NOTE_URL_LIST = [...]       # 指定笔记 URL 列表
XHS_CREATOR_ID_LIST = [...]               # 指定创作者 URL 列表
```

### 3.2 各平台通用配置模式

每个平台配置文件包含：
- `XXX_SPECIFIED_ID_LIST`：detail 模式下的帖子/视频 ID 列表
- `XXX_CREATOR_ID_LIST`：creator 模式下的创作者 ID 列表
- 平台特有的排序、过滤选项

## 5. 命令行接口 (`cmd_arg/arg.py`)

### 5.1 基于 Typer 的 CLI

项目使用 [Typer](https://typer.tiangolo.com/) 构建 CLI，支持丰富的参数：

```bash
python main.py [OPTIONS]
```

### 5.2 参数枚举

```python
class PlatformEnum(str, Enum):
    XHS = "xhs"       # 小红书
    DOUYIN = "dy"      # 抖音
    KUAISHOU = "ks"    # 快手
    BILIBILI = "bili"  # B站
    WEIBO = "wb"       # 微博
    TIEBA = "tieba"    # 贴吧
    ZHIHU = "zhihu"    # 知乎

class LoginTypeEnum(str, Enum):
    QRCODE = "qrcode"   # 二维码登录
    PHONE = "phone"      # 手机号登录
    COOKIE = "cookie"    # Cookie 登录

class CrawlerTypeEnum(str, Enum):
    SEARCH = "search"    # 关键词搜索
    DETAIL = "detail"    # 指定帖子详情
    CREATOR = "creator"  # 创作者主页

class SaveDataOptionEnum(str, Enum):
    CSV = "csv"
    DB = "db"            # MySQL
    JSON = "json"
    SQLITE = "sqlite"
    MONGODB = "mongodb"
    EXCEL = "excel"
    POSTGRES = "postgres"

class InitDbOptionEnum(str, Enum):
    SQLITE = "sqlite"
    MYSQL = "mysql"
    POSTGRES = "postgres"
```

### 5.3 所有 CLI 参数

| 参数 | 说明 | 分组 |
|------|------|------|
| `--platform` | 目标平台 | 基本配置 |
| `--type` | 爬虫类型（search/detail/creator） | 基本配置 |
| `--start` | 起始页码 | 基本配置 |
| `--keywords` | 搜索关键词（逗号分隔） | 基本配置 |
| `--specified_id` | 帖子 ID 列表（逗号分隔） | 基本配置 |
| `--creator_id` | 创作者 ID 列表（逗号分隔） | 基本配置 |
| `--lt` | 登录类型 | 账号配置 |
| `--cookies` | Cookie 值 | 账号配置 |
| `--get_comment` | 是否爬取评论 | 评论配置 |
| `--get_sub_comment` | 是否爬取二级评论 | 评论配置 |
| `--headless` | 是否无头模式 | 运行配置 |
| `--save_data_option` | 数据保存方式 | 存储配置 |
| `--init_db` | 初始化数据库 | 存储配置 |

### 5.4 参数覆盖机制

CLI 参数解析后会直接覆盖 `config` 模块中的全局变量：

```python
async def parse_cmd(argv=None):
    @app.callback(invoke_without_command=True)
    def main(platform=..., lt=..., ...):
        # CLI 参数直接覆盖全局 config
        config.PLATFORM = platform.value
        config.LOGIN_TYPE = lt.value
        config.CRAWLER_TYPE = crawler_type.value
        config.KEYWORDS = keywords
        config.HEADLESS = enable_headless
        config.SAVE_DATA_OPTION = save_data_option.value
        ...
        # 平台特有 ID 列表覆盖
        if specified_id_list:
            if platform == PlatformEnum.XHS:
                config.XHS_SPECIFIED_NOTE_URL_LIST = specified_id_list
            elif platform == PlatformEnum.BILIBILI:
                config.BILI_SPECIFIED_ID_LIST = specified_id_list
            ...
```

### 5.5 使用示例

```bash
# 小红书关键词搜索，保存为 JSON
python main.py --platform xhs --type search --keywords "AI创业,创业孵化" --save_data_option json

# 抖音指定视频详情，Cookie 登录
python main.py --platform dy --type detail --lt cookie --cookies "sid=xxx" --specified_id "7xxx,7yyy"

# B 站创作者模式，无头浏览器
python main.py --platform bili --type creator --creator_id "uid1,uid2" --headless true

# 初始化 SQLite 数据库
python main.py --init_db sqlite

# 微博搜索，爬取评论，保存到 MySQL
python main.py --platform wb --type search --keywords "热点话题" --get_comment true --save_data_option db
```

## 6. 环境变量配置 (`.env`)

```bash

MYSQL_DB_USER=root
MYSQL_DB_PWD=your_password
MYSQL_DB_NAME=media_crawler

# Redis
REDIS_DB_HOST=127.0.0.1
REDIS_DB_PWD=your_redis_pwd

# MongoDB
MONGODB_HOST=localhost
MONGODB_PORT=27017

# PostgreSQL
POSTGRES_DB_HOST=localhost
POSTGRES_DB_PORT=5432
POSTGRES_DB_USER=postgres
POSTGRES_DB_PWD=your_password
```

`.env.example` 提供了完整的配置模板参考。
