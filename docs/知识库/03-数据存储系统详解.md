# 数据存储系统详解

## 1. 存储架构概览

MediaCrawler 支持 7 种数据存储方式，通过 `config.SAVE_DATA_OPTION` 配置：

| 存储类型 | 配置值 | 适用场景 | 是否支持去重 |
|----------|--------|---------|-------------|
| CSV 文件 | `csv` | 快速导出、小数据量 | ❌ |
| JSON 文件 | `json` | 轻量级存储、数据分析 | ❌ |
| Excel 文件 | `excel` | 报告交付、非技术用户 | ❌ |
| MySQL | `db` | 大规模生产环境 | ✅ |
| SQLite | `sqlite` | 本地开发、单机部署 | ✅ |
| PostgreSQL | `postgres` | 企业级部署 | ✅ |
| MongoDB | `mongodb` | 灵活 Schema、大数据量 | ✅ |

## 2. 存储层架构

```
store/
├── __init__.py                 # 空模块入口
├── excel_store_base.py         # Excel 存储公共基类
│
├── xhs/                        # 小红书存储
│   ├── __init__.py             # XhsStoreFactory + update_xhs_note()
│   ├── _store_impl.py          # 6 种存储实现类
│   └── xhs_store_media.py      # 媒体文件存储
│
├── douyin/                     # 抖音存储
├── kuaishou/                   # 快手存储
├── bilibili/                   # B 站存储
├── weibo/                      # 微博存储
├── tieba/                      # 贴吧存储
├── zhihu/                      # 知乎存储
└── wechat/                     # 微信公众号存储
    ├── __init__.py             # WechatStoreFactory + update_wechat_article()
    ├── _store_impl.py          # 6 种存储实现类
    └── wechat_store_media.py   # 图片存储管理器（内容 hash 去重）
```

每个平台的存储模块包含：
- `__init__.py`：工厂类 + 数据规范化函数（如 `update_xhs_note()`）
- `_store_impl.py`：具体存储实现（6 个实现类）

## 3. StoreFactory 工厂模式

以小红书为例，`store/xhs/__init__.py` 中的 `XhsStoreFactory`：

```python
class XhsStoreFactory:
    STORES = {
        "csv":     XhsCsvStoreImplement,
        "db":      XhsDbStoreImplement,       # MySQL
        "postgres": XhsDbStoreImplement,       # PostgreSQL（复用 DB 实现）
        "json":    XhsJsonStoreImplement,
        "sqlite":  XhsSqliteStoreImplement,    # 继承自 XhsDbStoreImplement
        "mongodb": XhsMongoStoreImplement,
        "excel":   XhsExcelStoreImplement,
    }

    @staticmethod
    def create_store() -> AbstractStore:
        store_class = XhsStoreFactory.STORES.get(config.SAVE_DATA_OPTION)
        return store_class()
```

> SQLite 实现继承自 DB 实现（SQLAlchemy 统一处理），PostgreSQL 也复用 DB Store 实现。

## 4. 六种存储实现详解

### 4.1 CSV 存储 (`XhsCsvStoreImplement`)

```python
class XhsCsvStoreImplement(AbstractStore):
    def __init__(self):
        self.writer = AsyncFileWriter(platform="xhs", crawler_type=crawler_type_var.get())

    async def store_content(self, content_item: Dict):
        await self.writer.write_to_csv(item_type="contents", item=content_item)

    async def store_comment(self, comment_item: Dict):
        await self.writer.write_to_csv(item_type="comments", item=comment_item)
```

- 文件路径格式：`data/xhs/csv/{日期}_{关键词}_{爬虫类型}_{数据类型}.csv`
- 使用 `aiofiles` 异步写入，`asyncio.Lock` 保证线程安全
- 编码：UTF-8 with BOM (`utf-8-sig`)，便于 Excel 直接打开

### 4.2 JSON 存储 (`XhsJsonStoreImplement`)

- 文件路径格式：`data/xhs/json/{日期}_{关键词}_{爬虫类型}_{数据类型}.json`
- 每次写入读取全量 → 追加新项 → 重写全文件（适合中小数据量）
- 支持词云生成 (`ENABLE_GET_WORDCLOUD`)

### 4.3 数据库存储 (`XhsDbStoreImplement`)

核心依赖 SQLAlchemy 异步引擎：

```python
class XhsDbStoreImplement(AbstractStore):
    async def store_content(self, content_item: Dict):
        async with get_session() as session:
            # 查询是否已存在（去重）
            existing = await session.execute(
                select(XhsNote).where(XhsNote.note_id == note_id)
            )
            if existing.scalar():
                # UPDATE
                await session.execute(update(XhsNote).where(...).values(...))
            else:
                # INSERT
                session.add(XhsNote(**content_item))
```

支持的数据库后端：
- **MySQL**：通过 `asyncmy` 驱动
- **SQLite**：通过 `aiosqlite` 驱动
- **PostgreSQL**：通过 `asyncpg` 驱动

### 4.4 MongoDB 存储 (`XhsMongoStoreImplement`)

继承自 `MongoDBStoreBase`，使用 `motor` 异步驱动：

```python
class XhsMongoStoreImplement(AbstractStore):
    def __init__(self):
        self.mongo = MongoDBStoreBase()

    async def store_content(self, content_item: Dict):
        await self.mongo.upsert("xhs_notes", content_item, filter_key="note_id")
```

### 4.5 Excel 存储 (`XhsExcelStoreImplement`)

基于 `ExcelStoreBase`，在内存中缓存数据，程序结束时统一 flush 到 `.xlsx` 文件：

```python
# main.py 中的 flush 逻辑
def _flush_excel_if_needed():
    if config.SAVE_DATA_OPTION == "excel":
        ExcelStoreBase.flush_all()
```

## 5. 数据库模型定义

所有 ORM 模型定义在 `database/models.py`，基于 SQLAlchemy `declarative_base()`。每个平台定义了三类表：

### 5.1 小红书

| 模型类 | 表名 | 说明 |
|--------|------|------|
| `XhsNote` | `xhs_note` | 笔记内容 |
| `XhsNoteComment` | `xhs_note_comment` | 笔记评论 |
| `XhsCreator` | `xhs_creator` | 创作者信息 |

### 5.2 B 站

| 模型类 | 表名 | 说明 |
|--------|------|------|
| `BilibiliVideo` | `bilibili_video` | 视频内容 |
| `BilibiliVideoComment` | `bilibili_video_comment` | 视频评论 |
| `BilibiliUpInfo` | `bilibili_up_info` | UP 主信息 |
| `BilibiliContactInfo` | `bilibili_contact_info` | 联系信息 |
| `BilibiliUpDynamic` | `bilibili_up_dynamic` | 动态 |

### 5.3 微信公众号

| 模型类 | 表名 | 说明 |
|--------|------|------|
| `WechatArticle` | `wechat_article` | 文章内容（15 列：article_id, fakeid, title, link, digest, content, cover, image_list 等） |
| `WechatCreator` | `wechat_creator` | 公众号信息（fakeid, nickname, alias, signature, identity_name 等） |

> 微信模块不含评论表（微信 API 暂不支持评论获取）

### 5.4 类似结构（其他平台）

抖音、快手、微博、贴吧、知乎均遵循「内容 + 评论 + 创作者」三表结构。

## 6. 数据库 Session 管理

`database/db_session.py` 提供统一的异步数据库连接管理：

```python
# 引擎缓存（避免重复创建）
_engines = {}

def get_async_engine(db_type: str):
    """根据类型创建/获取异步引擎"""
    if db_type == "sqlite":
        db_url = f"sqlite+aiosqlite:///{sqlite_db_config['db_path']}"
    elif db_type in ("mysql", "db"):
        db_url = f"mysql+asyncmy://{user}:{password}@{host}:{port}/{db_name}"
    elif db_type == "postgres":
        db_url = f"postgresql+asyncpg://{user}:{password}@{host}:{port}/{db_name}"
    return create_async_engine(db_url, echo=False)

@asynccontextmanager
async def get_session() -> AsyncSession:
    """获取异步数据库 Session（上下文管理器）"""
    engine = get_async_engine(config.SAVE_DATA_OPTION)
    AsyncSessionFactory = sessionmaker(engine, class_=AsyncSession, expire_on_commit=False)
    session = AsyncSessionFactory()
    try:
        yield session
        await session.commit()
    except Exception:
        await session.rollback()
        raise
```

## 7. 数据库初始化

```bash
# 初始化 SQLite
python main.py --init_db sqlite

# 初始化 MySQL
python main.py --init_db mysql

# 初始化 PostgreSQL
python main.py --init_db postgres
```

初始化流程：
1. `db.init_db(db_type)` → `create_tables(db_type)`
2. 对 MySQL/PostgreSQL：先创建数据库（`CREATE DATABASE IF NOT EXISTS`）
3. 调用 `Base.metadata.create_all(engine)` 创建所有表

## 8. 数据规范化层

每个平台的 `store/__init__.py` 中包含数据规范化函数，负责将 API 原始响应转换为统一格式：

```python
# store/xhs/__init__.py
async def update_xhs_note(note_item: Dict):
    """规范化小红书笔记数据"""
    note_id = note_item.get("note_id")
    user_info = note_item.get("user", {})
    interact_info = note_item.get("interact_info", {})
    image_list = note_item.get("image_list", [])
    tag_list = note_item.get("tag_list", [])

    # 构建标准化字段
    save_content = {
        "note_id": note_id,
        "title": note_item.get("title", ""),
        "desc": note_item.get("desc", ""),
        "type": note_item.get("type", ""),
        "user_id": user_info.get("user_id", ""),
        "nickname": user_info.get("nickname", ""),
        "liked_count": interact_info.get("liked_count", ""),
        "collected_count": interact_info.get("collected_count", ""),
        "comment_count": interact_info.get("comment_count", ""),
        ...
    }

    # 写入存储
    store = XhsStoreFactory.create_store()
    await store.store_content(save_content)
```

## 10. 数据库配置参考

所有数据库连接配置集中在 `config/db_config.py`，支持环境变量覆盖：

| 配置项 | 环境变量 | 默认值 |
|--------|---------|--------|
| MySQL 主机 | `MYSQL_DB_HOST` | localhost |
| MySQL 端口 | `MYSQL_DB_PORT` | 3306 |
| MySQL 用户 | `MYSQL_DB_USER` | root |
| MySQL 密码 | `MYSQL_DB_PWD` | 123456 |
| MySQL 库名 | `MYSQL_DB_NAME` | media_crawler |
| SQLite 路径 | - | `database/sqlite_tables.db` |
| PostgreSQL 主机 | `POSTGRES_DB_HOST` | localhost |
| PostgreSQL 端口 | `POSTGRES_DB_PORT` | 5432 |
| MongoDB 主机 | `MONGODB_HOST` | localhost |
| MongoDB 端口 | `MONGODB_PORT` | 27017 |
| Redis 主机 | `REDIS_DB_HOST` | 127.0.0.1 |
| Redis 端口 | `REDIS_DB_PORT` | 6379 |
