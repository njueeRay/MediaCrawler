# 平台爬虫模块详解

## 1. 模块总览

`media_platform/` 目录下包含 8 个平台的爬虫实现，每个平台遵循统一的模块结构（微信公众号为纯 API 消费，无浏览器依赖）：

| 平台 | 目录 | 标识 | 目标站点 |
|------|------|------|----------|
| 小红书 | `media_platform/xhs/` | `xhs` | xiaohongshu.com |
| 抖音 | `media_platform/douyin/` | `dy` | douyin.com |
| 快手 | `media_platform/kuaishou/` | `ks` | kuaishou.com |
| B站 | `media_platform/bilibili/` | `bili` | bilibili.com |
| 微博 | `media_platform/weibo/` | `wb` | weibo.com |
| 百度贴吧 | `media_platform/tieba/` | `tieba` | tieba.baidu.com |
| 知乎 | `media_platform/zhihu/` | `zhihu` | zhihu.com |
| 微信公众号 | `media_platform/wechat/` | `wechat` | mp.weixin.qq.com（通过 wechat-article-exporter API） |

## 2. 统一模块结构

每个平台目录下包含以下标准文件：

```
media_platform/<platform>/
├── __init__.py         # 导出 XxxCrawler 类
├── core.py             # 【核心】爬虫主逻辑，继承 AbstractCrawler
├── client.py           # API 客户端，继承 AbstractApiClient + ProxyRefreshMixin
├── login.py            # 登录逻辑，继承 AbstractLogin
├── field.py            # 枚举 & 常量定义（排序类型、笔记类型等）
├── help.py             # 辅助函数（URL 解析、ID 提取等）
└── exception.py        # 平台特定异常（DataFetchError, IPBlockError 等）
```

> 小红书额外包含 `extractor.py`（HTML 内容提取）、`playwright_sign.py` 和 `xhs_sign.py`（请求签名）；快手额外包含 `graphql.py` 和 `graphql/` 目录（GraphQL 查询）。

## 3. 抽象基类体系

所有抽象基类定义在 `base/base_crawler.py` 中：

### 3.1 AbstractCrawler

```python
class AbstractCrawler(ABC):
    async def start(self):                    # 主入口（模板方法）
    async def search(self):                   # 关键词搜索
    async def launch_browser(self, ...):      # 标准模式启动浏览器
    async def launch_browser_with_cdp(self, ...):  # CDP 模式启动浏览器
```

### 3.2 AbstractLogin

```python
class AbstractLogin(ABC):
    async def begin(self):                    # 登录入口
    async def login_by_qrcode(self):          # QR码登录
    async def login_by_mobile(self):          # 手机号登录
    async def login_by_cookies(self):         # Cookie 登录
```

### 3.3 AbstractApiClient

```python
class AbstractApiClient(ABC):
    async def request(self, method, url, **kwargs):   # 通用请求
    async def update_cookies(self, browser_context):  # 从浏览器同步 Cookie
```

### 3.4 AbstractStore

```python
class AbstractStore(ABC):
    async def store_content(self, content_item: Dict):    # 存储内容
    async def store_comment(self, comment_item: Dict):    # 存储评论
    async def store_creator(self, creator: Dict):         # 存储创作者
```

## 4. 以小红书为例的完整流程

### 4.1 `XiaoHongShuCrawler.start()` 流程

```
start()
  │
  ├── 1. 初始化代理 IP 池（如果 ENABLE_IP_PROXY=True）
  │       create_ip_pool() → ProxyIpPool
  │
  ├── 2. 启动浏览器
  │       ├── ENABLE_CDP_MODE=True  → CDPBrowserManager.launch_and_connect()
  │       │      └── 检测 Chrome/Edge → 启动 CDP 进程 → Playwright 连接
  │       └── ENABLE_CDP_MODE=False → playwright.chromium.launch()
  │              └── 注入 stealth.min.js 反检测脚本
  │
  ├── 3. 创建客户端
  │       XiaoHongShuClient(headers, playwright_page, cookie_dict, proxy_ip_pool)
  │
  ├── 4. 检查登录状态
  │       xhs_client.pong()  →  如果未登录：
  │       └── XiaoHongShuLogin.begin()
  │              ├── login_by_qrcode()  → 扫码登录
  │              ├── login_by_mobile()  → 手机号+验证码
  │              └── login_by_cookies() → 直接设置Cookie
  │
  ├── 5. 分发爬虫任务
  │       ├── CRAWLER_TYPE="search"  → search()
  │       ├── CRAWLER_TYPE="detail"  → get_specified_notes()
  │       └── CRAWLER_TYPE="creator" → get_creators_and_notes()
  │
  └── 6. search() 内部流程
          ├── 遍历关键词
          ├── 分页请求 get_note_by_keyword()
          ├── 并发获取笔记详情 get_note_detail_async_task()
          │       └── asyncio.Semaphore 控制并发数
          ├── 过滤时间范围
          ├── 存储到 store → xhs_store.update_xhs_note()
          ├── 下载媒体资源 get_notice_media()
          ├── 批量获取评论 batch_get_note_comments()
          └── 间隔休眠 asyncio.sleep(CRAWLER_MAX_SLEEP_SEC)
```

### 4.2 XiaoHongShuClient 请求签名

小红书 API 需要复杂的请求签名，项目通过 Playwright 注入 JS 方式实现：

```
client._pre_headers(url, params/payload)
  │
  └── sign_with_playwright(page, uri, data, a1, method)
         │
         └── 在浏览器上下文中执行 JS 签名脚本
                生成: x-s, x-t, x-s-common, x-b3-traceid
```

关键头部参数：
- `X-S`: 签名值
- `X-T`: 时间戳
- `X-S-Common`: 通用签名
- `X-B3-Traceid`: 追踪 ID

### 4.3 登录状态检测

`XiaoHongShuLogin.check_login_state()` 使用三重检测机制：
1. **UI 检测**：查找页面中"我"按钮（`/user/profile/`链接）
2. **验证码检测**：页面中包含"请通过验证"
3. **Cookie 变化检测**：`web_session` Cookie 值是否改变

## 5. 平台差异对比

### 5.1 签名机制

| 平台 | 签名方式 | 相关文件 |
|------|----------|----------|
| 小红书 | Playwright JS 注入签名 | `playwright_sign.py`, `xhs_sign.py` |
| 抖音 | JS 注入签名 | `libs/douyin.js` |
| 知乎 | JS 注入签名 | `libs/zhihu.js` |
| 快手 | GraphQL 查询 | `graphql.py`, `graphql/` |
| B站 | Cookie + 标准头部 | `client.py` |
| 微博 | Cookie + 标准头部 | `client.py` |
| 贴吧 | 直接请求 | `client.py` |
| 微信公众号 | 无签名（Auth-Key 认证） | `client.py`（httpx → wechat-article-exporter API） |

### 5.2 浏览器启动模式

除微信公众号外，所有平台均支持两种模式：
- **标准模式** (Playwright launch)：使用 Playwright 内置 Chromium，注入 `stealth.min.js` 反检测
- **CDP 模式** (Chrome DevTools Protocol)：连接用户已安装的 Chrome/Edge 浏览器，反检测能力更强
- **微信公众号**：不使用浏览器，`launch_browser` 为空实现，纯 httpx HTTP 调用

### 5.3 数据实体差异

| 平台 | 主要内容类型 | 评论结构 | 创作者信息 |
|------|-------------|---------|-----------|
| 小红书 | 笔记 (Note) | 一级 + 二级评论 | 完整个人主页 |
| 抖音 | 视频 (Video) | 一级 + 二级评论 | 创作者主页 |
| 快手 | 视频 (Video) | 一级 + 二级评论 | 创作者主页 |
| B站 | 视频 (Video) + 动态 | 一级 + 二级评论 | UP主信息 |
| 微博 | 微博 (Post) | 一级 + 二级评论 | 博主信息 |
| 贴吧 | 帖子 (Thread) | 楼层评论 | 不支持 |
| 知乎 | 回答/文章 | 一级 + 二级评论 | 知乎用户 |
| 微信公众号 | 文章 (Article) | 不支持（待 API 扩展） | 公众号主体信息 |

## 6. 三种爬虫类型

### 6.1 search（关键词搜索）

根据配置的关键词列表 `config.KEYWORDS`，在目标平台搜索并抓取结果：
- 支持分页控制（`START_PAGE`, `CRAWLER_MAX_NOTES_COUNT`）
- 支持排序方式（`SORT_TYPE`）
- 支持时间范围筛选（`XHS_ENABLE_TIME_RANGE`）

### 6.2 detail（指定帖子详情）

直接传入帖子/视频 URL 或 ID 列表，抓取指定内容的详细信息和评论：
- 通过 `--specified_id` 参数或配置文件中的 URL 列表指定
- 每个平台有独立的 ID 列表配置项（如 `XHS_SPECIFIED_NOTE_URL_LIST`）

### 6.3 creator（创作者主页）

抓取指定创作者的所有公开内容：
- 通过 `--creator_id` 参数或配置文件中的创作者列表指定
- 遍历创作者主页获取帖子列表，再逐个获取详情+评论
