# 工具链与基础设施

## 1. 概述

`tools/`、`proxy/`、`cache/` 目录构成了 MediaCrawler 的基础设施层，提供浏览器管理、代理 IP、缓存、文件写入、验证码处理等跨平台公共能力。

## 2. 浏览器管理

### 2.1 双模式架构

MediaCrawler 支持两种浏览器启动模式，通过 `config.ENABLE_CDP_MODE` 控制：

```
ENABLE_CDP_MODE=False (标准模式)          ENABLE_CDP_MODE=True (CDP 模式)
┌──────────────────────┐           ┌──────────────────────┐
│   Playwright 内置     │           │  用户现有 Chrome/Edge  │
│   Chromium 浏览器     │           │  通过 CDP 协议连接     │
├──────────────────────┤           ├──────────────────────┤
│ + 环境干净可控        │           │ + 真实浏览器环境       │
│ + 自动管理生命周期    │           │ + 用户 Cookie/扩展     │
│ - 容易被反爬检测      │           │ + 反检测能力强        │
│ - 需要注入 stealth.js │           │ - 需要本机安装浏览器   │
└──────────────────────┘           └──────────────────────┘
```

### 2.2 CDPBrowserManager (`tools/cdp_browser.py`)

负责 CDP 模式下浏览器的完整生命周期管理：

```python
class CDPBrowserManager:
    async def launch_and_connect(self, playwright, ...):
        # 1. 检测浏览器路径 (_get_browser_path)
        #    - 优先使用 CUSTOM_BROWSER_PATH
        #    - 自动检测 Chrome/Edge 安装路径
        #
        # 2. 获取可用端口 (find_available_port)
        #    - 从 CDP_DEBUG_PORT(默认 9222) 开始
        #    - 端口被占用则自动+1
        #
        # 3. 启动浏览器进程 (_launch_browser)
        #    - 设置用户数据目录 (browser_data/cdp_xxx_user_data_dir)
        #    - 传入 remote-debugging-port 参数
        #
        # 4. 注册清理处理器 (_register_cleanup_handlers)
        #    - atexit 注册进程清理
        #    - SIGINT/SIGTERM 信号处理
        #
        # 5. 通过 CDP 连接 (_connect_via_cdp)
        #    - playwright.chromium.connect_over_cdp()
        #
        # 6. 创建 BrowserContext
```

关键配置项：
- `ENABLE_CDP_MODE`：是否启用 CDP 模式
- `CDP_DEBUG_PORT`：CDP 调试端口（默认 9222）
- `CUSTOM_BROWSER_PATH`：自定义浏览器路径
- `CDP_HEADLESS`：CDP 模式下的无头模式
- `SAVE_LOGIN_STATE`：是否保存登录状态到用户数据目录
- `AUTO_CLOSE_BROWSER`：程序结束时是否关闭浏览器

### 2.3 BrowserLauncher (`tools/browser_launcher.py`)

跨平台浏览器路径检测与进程启动工具：
- 自动检测 Windows/macOS/Linux 上的 Chrome 和 Edge
- 端口可用性检测
- 获取浏览器名称和版本信息

### 2.4 反检测脚本 (`libs/`)

libs/

## 3. 代理 IP 池系统

### 3.1 架构图

```
config.ENABLE_IP_PROXY = True
        │
        ▼
 create_ip_pool(count, enable_validate)
        │
        ▼
 ┌─────────────────────┐
 │    ProxyIpPool       │  ← 代理池管理
 │  ├── load_proxies()  │  ← 从提供商批量获取
 │  ├── get_proxy()     │  ← 随机取一个可用代理
 │  └── is_expired()    │  ← 检查代理是否过期
 └─────────┬───────────┘
           │
    ┌──────┴──────┐
    ▼             ▼
┌────────┐  ┌──────────┐
│ 快代理  │  │ 豌豆 HTTP │  ← ProxyProvider 实现
└────────┘  └──────────┘
```

### 3.2 核心类

**IpInfoModel** (`proxy/types.py`)：
```python
class IpInfoModel(BaseModel):
    ip: str
    port: int
    user: str                           # 认证用户名
    password: str                       # 认证密码
    protocol: str = "https://"
    expired_time_ts: Optional[int]      # 到期时间戳

    def is_expired(self, buffer_seconds=30) -> bool:
        """提前 30 秒判定过期"""
```

**ProxyProvider** (`proxy/base_proxy.py`)：
```python
class ProxyProvider(ABC):
    @abstractmethod
    async def get_proxy(self, num: int) -> List[IpInfoModel]:
        """从代理商获取指定数量的IP"""
```

**ProxyIpPool** (`proxy/proxy_ip_pool.py`)：
```python
class ProxyIpPool:
    def __init__(self, ip_pool_count, enable_validate_ip, ip_provider):
        self.proxy_list: List[IpInfoModel] = []
        self.current_proxy: IpInfoModel | None = None

    async def load_proxies(self):        # 批量加载代理
    async def get_proxy(self) -> IpInfoModel:  # 随机获取一个（带验证）
    def is_current_proxy_expired(self) -> bool:  # 当前代理是否过期
    async def get_or_refresh_proxy(self):       # 获取或刷新代理
```

### 3.3 ProxyRefreshMixin (`proxy/proxy_mixin.py`)

Mixin 类，混入到各平台 Client 中，实现请求前自动刷新过期代理：

```python
class ProxyRefreshMixin:
    def init_proxy_pool(self, proxy_ip_pool):
        self._proxy_ip_pool = proxy_ip_pool

    async def _refresh_proxy_if_expired(self):
        """每次请求前调用，自动检测并刷新过期代理"""
        if self._proxy_ip_pool.is_current_proxy_expired():
            new_proxy = await self._proxy_ip_pool.get_or_refresh_proxy()
            self.proxy = f"http://{new_proxy.ip}:{new_proxy.port}"
```

使用方式（以小红书客户端为例）：
```python
class XiaoHongShuClient(AbstractApiClient, ProxyRefreshMixin):
    def __init__(self, ..., proxy_ip_pool=None):
        self.init_proxy_pool(proxy_ip_pool)  # 初始化代理池

    async def request(self, method, url, **kwargs):
        await self._refresh_proxy_if_expired()  # 每次请求前检查
        ...
```

### 4.2 CacheFactory

```python
class CacheFactory:
    @staticmethod
    def create_cache(cache_type: str):
        if cache_type == 'memory':
            return ExpiringLocalCache()
        elif cache_type == 'redis':
            return RedisCache()
```

配置项：`config.CACHE_TYPE_REDIS = "redis"`, `config.CACHE_TYPE_MEMORY = "memory"`

## 6. 优雅启停 (`tools/app_runner.py`)

```python
def run(app_main, app_cleanup, *, cleanup_timeout_seconds=15.0):
    """
    运行异步应用，处理信号和清理：
    1. 注册 SIGINT/SIGTERM 信号处理器
    2. 运行主函数 app_main()
    3. 收到中断信号后：
       - 第一次：进入优雅关闭，执行 app_cleanup()（最长 15 秒）
       - 第二次：强制退出 os._exit()
    4. 取消所有剩余异步任务
    """
```

`main.py` 中的使用：
```python
if __name__ == "__main__":
    from tools.app_runner import run
    run(
        main,
        async_cleanup,
        on_first_interrupt=lambda: print("\n[Main] Cleanup in progress..."),
    )
```

## 7. 日志系统

`tools/utils.py` 初始化全局日志：

```python
def init_loging_config():
    logging.basicConfig(
        level=logging.INFO,
        format="%(asctime)s %(name)s %(levelname)s (%(filename)s:%(lineno)d) - %(message)s",
        datefmt='%Y-%m-%d %H:%M:%S'
    )
    _logger = logging.getLogger("MediaCrawler")
    # 屏蔽 httpx 的 INFO 级别日志
    logging.getLogger("httpx").setLevel(logging.WARNING)
    return _logger

logger = init_loging_config()
```

所有模块通过 `from tools import utils` → `utils.logger.info(...)` 使用统一日志。

## 8. ContextVar 上下文变量 (`var.py`)

```python
request_keyword_var: ContextVar[str]     # 当前请求关键词
crawler_type_var: ContextVar[str]        # 爬虫类型（search/detail/creator）
comment_tasks_var: ContextVar[List[Task]] # 评论获取任务列表
db_conn_pool_var: ContextVar[aiomysql.Pool] # MySQL 连接池
source_keyword_var: ContextVar[str]      # 来源关键词（用于文件命名）
```

`ContextVar` 的优势：在 asyncio 并发任务中安全传递上下文，每个异步任务链拥有独立的值。
