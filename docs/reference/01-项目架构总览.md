# MediaCrawler 项目架构总览

## 1. 项目简介

MediaCrawler 是一个多平台社交媒体数据采集框架，支持从小红书、抖音、快手、B站、微博、百度贴吧、知乎、微信公众号等 8 个主流平台抓取帖子/视频内容、评论及创作者信息。项目基于 Python 异步编程（asyncio）和 Playwright 浏览器自动化技术构建（微信公众号模块为纯 API 消费，不使用浏览器），提供了统一的抽象接口和插件化的平台适配层。

## 2. 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Python 3.11+ |
| 异步框架 | asyncio |
| 浏览器自动化 | Playwright (标准模式 + CDP 模式) |
| HTTP 客户端 | httpx |
| 数据库 ORM | SQLAlchemy (异步) |
| 数据验证 | Pydantic |
| CLI | Typer |
| 重试机制 | Tenacity |
| 缓存 | Redis / 本地内存缓存 |
| WebUI API | FastAPI + uvicorn |
| 包管理 | uv / Yarn 1 (Corepack) |

## 5. 核心设计模式

### 5.1 工厂模式 (Factory Pattern)

- **CrawlerFactory** (`main.py`)：根据平台标识创建对应的爬虫实例
- **StoreFactory**（每个 `store/<platform>/__init__.py`）：根据存储选项创建对应的 Store 实现
- **CacheFactory** (`cache/cache_factory.py`)：根据缓存类型创建 Redis 或内存缓存

### 5.2 模板方法模式 (Template Method)

每个平台的 `core.py` 继承 `AbstractCrawler`，实现统一的 `start()` → `search()`/`get_specified_notes()`/`get_creators_and_notes()` 流程：
1. 初始化代理 IP 池
2. 启动浏览器（标准模式 / CDP 模式）
3. 创建平台客户端
4. 检查登录状态并执行登录
5. 根据爬虫类型分发到具体任务
6. 数据写入存储层

### 5.3 策略模式 (Strategy Pattern)

- **存储策略**：CSV / JSON / MySQL / SQLite / PostgreSQL / MongoDB / Excel 均实现 `AbstractStore` 接口
- **登录策略**：QR码 / 手机号 / Cookie 三种登录方式
- **代理策略**：快代理 / 豌豆HTTP 等不同代理商

### 5.4 Mixin 模式

- `ProxyRefreshMixin`：混入到各平台 Client 中，在每次请求前自动检查代理是否过期并刷新

### 5.5 ContextVar 上下文传递

通过 `var.py` 中的 `ContextVar` 在异步调用链中传递爬虫类型、关键词、数据库连接池等上下文信息，避免全局变量污染。

## 6. 数据流概览

```
用户输入 (CLI参数/WebUI配置)
    │
    ▼
config 模块加载配置
    │
    ▼
CrawlerFactory.create_crawler(platform)
    │
    ▼
XxxCrawler.start()
    │
    ├──► 浏览器启动 (Playwright/CDP)
    ├──► 登录验证 (XxxLogin)
    ├──► API 请求 (XxxClient → httpx)
    │       │
    │       ├──► 签名注入 (Playwright JS eval)
    │       └──► 代理刷新 (ProxyRefreshMixin)
    │
    ├──► 数据解析 & 规范化
    │
    └──► 数据存储 (XxxStoreFactory)
            │
            ├──► CSV / JSON / Excel (AsyncFileWriter)
            ├──► MySQL / SQLite / PostgreSQL (SQLAlchemy async)
            └──► MongoDB (Motor)
```

## 7. 运行方式

### 7.1 CLI 模式

```bash
# 基本用法
python main.py --platform xhs --type search --keywords "关键词"

# 指定存储和登录方式
python main.py --platform dy --lt cookie --cookies "xxx" --save_data_option json

# 初始化数据库
python main.py --init_db sqlite
```

### 7.2 WebUI 模式

```bash
uvicorn api.main:app --port 8080 --reload
```

### 7.3 定时调度

```bash
python auto_scheduler.py
```
