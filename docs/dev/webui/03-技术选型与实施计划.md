# MediaCrawler WebUI — 技术选型与实施计划

> 版本: v0.2 Draft | 日期: 2026-02-11

---

## 1. 技术选型

### 1.1 前端技术栈

| 技术 | 选型 | 理由 |
|------|------|------|
| **框架** | Vue 3 (Composition API) | 与 wechat_crawler 项目保持一致；生态丰富 |
| **构建** | Vite 6 | 快速 HMR，现有构建产物即来自 Vite |
| **UI 库** | Naive UI | 企业级 Vue 3 组件库，自带暗色主题，表格/表单能力强，中文文档完善 |
| **样式** | TailwindCSS 4 | 原子化 CSS，快速布局，不需要复杂自定义样式 |
| **状态管理** | Pinia | Vue 3 官方推荐，简洁直观 |
| **路由** | Vue Router 4 | SPA 页面导航 |
| **HTTP** | Axios | 请求封装、拦截器、错误处理 |
| **WebSocket** | 原生 + reconnecting-ws | 实时日志推送 |
| **图表** | ECharts (可选) | 仪表盘数据可视化 |
| **表格** | Naive UI DataTable | 内置排序、筛选、虚拟滚动 |
| **图标** | @vicons/ionicons5 | Naive UI 推荐的图标库 |
| **TypeScript** | TypeScript 5 | 类型安全 |

### 1.2 后端技术栈 (扩展现有)

| 技术 | 选型 | 理由 |
|------|------|------|
| **框架** | FastAPI (已有) | 高性能异步框架，已经搭建好 |
| **ORM** | SQLAlchemy 2.0 (已有) | 已有数据模型，扩展新表 |
| **任务调度** | APScheduler 4 | 替代现有 `schedule` 库，支持持久化、Cron 表达式、任务管理 API |
| **配置管理** | python-dotenv (已有) | .env 读写 |
| **WebSocket** | FastAPI WebSocket (已有) | 实时通信 |
| **数据验证** | Pydantic v2 (已有) | 请求/响应模型 |
| **飞书 SDK** | lark-oapi (已有) | 飞书 API 交互 |

### 1.3 开发工具

| 工具 | 用途 |
|------|------|
| uv | Python 包管理 (项目已使用) |
| pnpm | 前端包管理 |
| Biome | 前端代码格式化/检查 |
| Ruff | Python 代码格式化/检查 |

### 3.1 现有文件改动清单

仅 **4 个现有文件** 需要小幅修改，改动内容均为追加 import/注册语句：

| 文件 | 改动类型 | 改动行数 | 说明 |

| `api/main.py` | 追加 | ~12 行 | 5 个 `include_router()` + startup 调用 `seed_default_mappings()` |

**零破坏性变更** —— 不删除/重命名/重构任何已有代码。

## 6. 开发工作流

### 6.1 日常开发

```bash
# 终端 1: 后端
cd MediaCrawler
uv run uvicorn api.main:app --reload --port 8080

# 终端 2: 前端
cd MediaCrawler/webui-src
pnpm dev  # Vite dev server at :3000, proxy /api → :8080
```

### 6.2 构建部署

```bash
# 前端构建
cd webui-src
pnpm build  # 输出到 ../api/webui/

# 一体化运行
uv run uvicorn api.main:app --port 8080
# 访问 http://localhost:8080 即可
```
