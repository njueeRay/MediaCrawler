## 系统概要

### 解决什么问题

将 MediaCrawler 的「命令行爬虫 + 脚本同步 + 手动配置」工作方式，升级为：

```
之前:  编辑 .env → 命令行跑爬虫 → 手动处理 CSV → 跑脚本同步飞书
之后:  网页配置 → 订阅创作者 → 自动采集 → 可视化浏览 → 一键同步飞书
```

### 8 大功能模块

├──────────┬──────────┬──────────┬─────────────────┤

├──────────┼──────────┼──────────┼─────────────────┤

### 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Vue 3 + Vite + Naive UI + TailwindCSS + Pinia |
| 后端 | FastAPI (已有, 扩展) + SQLAlchemy + APScheduler |
| 存储 | SQLite (默认) / MySQL / PostgreSQL |
| 外部 | wechat-article-exporter (微信源) + 飞书 API (lark-oapi) |

## 快速启动

```bash
# 1. 安装依赖
cd MediaCrawler
uv pip install -r requirements.txt

# 2. 启动后端 (默认 CSV 模式; 切 DB 需在配置管理页修改)
uv run uvicorn api.main:app --port 8080

# 3. 访问 WebUI
# 浏览器打开 http://localhost:8080

# (可选) 前端开发模式
cd webui-src
yarn install
yarn dev   # -> http://localhost:3000 (代理 API 到 8080)
```
