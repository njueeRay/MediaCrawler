### 设计原则
- `config/base_config.py`：变量定义与默认值（`_env(...)`）
- `api/services/config_service.py`：只基于“配置元数据注册表”构建 UI schema
- `api/routers/config.py`：只做入参校验 + service 调用

- [ ] 启动时执行一致性校验：

  - [ ] 返回缺失必填项
