## 模块 2: 配置管理 (Config Manager)

### 2.1 功能描述

以可视化表单管理 `.env` 中的所有配置项，替代手动编辑文件。

### 2.2 页面布局

```

│                                                               │
│  ┌─分类标签──────────────────────────────────────────────┐   │
│  │ [飞书配置] [数据库配置] [微信源配置] [代理配置] [通用]  │   │
│  └────────────────────────────────────────────────────────┘   │
│                                                               │
│  ── 飞书配置 ────────────────────────────────────────────     │
│                                                               │
│  App ID           [fei_xxxxxxxxxxxxx        ]  ℹ️ 飞书应用ID │
│  App Secret       [••••••••••••••••         ]  👁 显示/隐藏   │
│  App Token        [bascnXXXXXXXXXXX        ]  ℹ️ 多维表格Token│
│  Table ID         [tblXXXXXXXXXXXXX        ]  ℹ️ 可选,自动创建│
│  批量大小          [500                      ]  ℹ️ 每批写入条数 │
│  同步间隔(秒)      [300                      ]  ℹ️ 自动同步间隔 │
│                                                               │
│  ┌────────────────────────────────────────────────────────┐  │
│  │  [🔍 测试连接]          [💾 保存配置]  [↩ 重置]        │  │
│  └────────────────────────────────────────────────────────┘  │
│                                                               │
│  ── 当前 .env 文件预览 (只读) ────────────────────────────    │
│  ┌────────────────────────────────────────────────────────┐  │
│  │ FEISHU_APP_ID=fei_xxxxxxxxxxxxx                        │  │
│  │ FEISHU_APP_SECRET=****                                 │  │
│  │ FEISHU_APP_TOKEN=bascnXXXXXXXXXXX                     │  │
│  │ ...                                                    │  │
│  └────────────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────────────┘
```

### 2.3 配置分组

| 分组 | 配置项 | 环境变量 |
|------|--------|----------|
| **飞书** | App ID, App Secret, App Token, Table ID, 批量大小, 同步间隔 | `FEISHU_APP_*` |
| **数据库** | 类型(SQLite/MySQL/PG), 主机, 端口, 用户名, 密码, 数据库名 | `DB_*`, `MYSQL_*`, `PG_*` |
| **微信源** | API 地址, Auth Key | `WECHAT_API_BASE_URL`, `WECHAT_AUTH_KEY` |
| **代理** | 代理类型, 代理地址, 认证信息 | `PROXY_*` |
| **通用** | 日志级别, 数据存储方式, Headless 模式, 并发数 | `SAVE_DATA_OPTION`, `HEADLESS`, etc. |
| **高级** | WebUI 认证, Debug 模式, 自定义 User-Agent | `WEBUI_AUTH_*`, `DEBUG_*` |

### 2.4 交互特性

- **分组 Tab 切换**：配置按类别分组，快速定位
- **输入验证**：必填项校验、格式校验（如 URL 格式）
- **敏感值脱敏**：API Secret 等默认掩码显示，点击切换
- **测试连接**：飞书/数据库/微信源 支持一键测试连接
- **保存即生效**：保存后自动重载环境变量，无需重启
- **变更历史**：记录配置变更日志（谁在什么时间改了什么）

### 5.3 功能点

| 功能 | 说明 |
|------|------|
| 字段启用/禁用 | 勾选控制字段是否参与导出和同步 |
| 显示名自定义 | 编辑「显示名称」列，定义在飞书/导出中使用的名称 |
| 飞书列类型 | 下拉选择飞书多维表格的列类型（文本/数字/日期/单选/多选/超链接/附件）|
| 字段排序 | 拖拽或上下箭头调整字段顺序 |
| 方案管理 | 保存多套映射方案，按场景切换（如"飞书完整版"、"CSV精简版"）|
| 实时预览 | 输入样本数据，实时预览映射效果 |
| 跨平台模板 | 将一个平台的映射方案复制为其他平台的模板 |

系统预设各平台的默认映射（参考现有 `data_formatter.py`），用户可在此基础上修改：

| Douyin | aweme_id, title, desc, liked_count, comment_count, share_count, time | 视频ID, 标题, 描述, 点赞数, 评论数, 分享数, 发布时间 |
| ... | ... | ... |

### 7.3 任务类型

| 类型 | 说明 | 配置项 |
|------|------|--------|
| **采集任务** | 运行爬虫采集内容 | 平台、模式(订阅/搜索/指定)、关键词、页数 |
| **同步任务** | 将数据同步到飞书 | 数据源、映射方案、日期范围、目标表 |
| **清理任务** | 清理过期数据/日志 | 保留天数、清理类型 |
| **组合任务** | 采集 + 同步 串联 | 先采集后同步，采集配置 + 同步配置 |

### 7.4 调度选项

| 周期 | 格式 | 示例 |
|------|------|------|
| 每 N 分钟 | 间隔 | 每 30 分钟 |
| 每 N 小时 | 间隔 | 每 6 小时 |
| 每天 | 固定时间 | 每天 08:00 |
| 每周 | 星期几 + 时间 | 每周一 09:00 |
| Cron 表达式 | 高级 | `0 */6 * * *` |
