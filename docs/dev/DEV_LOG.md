## 2026-01-29

### Feishu 同步改动（精简记录）

- 统一 `sync_data` 支持文件路径输入（CSV/JSON），加载逻辑内聚到 `FeishuSyncManager`。
- 新增字段过滤：上传前仅保留表内已有字段，避免缺字段导致报错，默认只追加不覆盖。
- 追加写入支持 CSV/JSON 自动识别；无需额外开关，使用 `--append-table-id` 指定目标表即可。
- 追加时可设置固定字段（如 `type=黑客松`），支持单选/多选选项配置与自动建字段。
- 修复字段类型转换：
  - 超链接/附件字段保留对象结构，不再强制转字符串。
  - 单选不再强制布尔值；多选支持列表写入。
- 修复新增字段导致主字段被改名问题：新增字段不再触发主字段重命名。
- 更新 `docs/feishu/飞书开发说明.md`：补充追加写入、额外字段参数说明与类型编号对照。
- 新增读取能力：`read_from_feishu.py` 支持字段过滤、选列读取与导出 CSV。
- CSV JSON 同步支持多列解析与普通列保留参数，批量写入保持追加模式。
- 笔记链接上传前自动清理 `xsec_token`、`xsec_source` 等私参，确保多维表只展示干净链接。
- 上传时会读取远程字段类型并按类型转换值，减少字段类型不匹配导致的报错。
