## 一、项目目标

将微信公众号爬虫能力集成到 MediaCrawler，实现：

- 给定**多个公众号 fakeid 列表**，批量爬取其全部/指定数量的文章
- 获取**文章文本内容**（支持 HTML / Markdown / 纯文本 / JSON 四种格式）
- 下载**文章中嵌入的图片资源**到本地
- 支持 search / detail / creator 三种爬取模式
- 数据存储对齐 MediaCrawler 现有多后端（CSV / JSON / DB / SQLite / Excel / MongoDB）

## 二、核心技术路线

**不重写，做 API 消费者。**

wechat-article-exporter 已解决微信公众平台的登录认证、Cookie 管理、请求代理、HTML 归一化等所有复杂问题，并暴露了标准化 HTTP API。MediaCrawler 端只需用 httpx 调用这些 API。

| 层 | 方案 |
|---|---|
| 认证 | Auth-Key（请求头 `X-Auth-Key`），有效期约 4 天 |
| 请求 | httpx AsyncClient → wechat-article-exporter 公开 API |
| 浏览器 | **完全不需要**（launch_browser 空实现） |
| 内容解析 | `/api/public/v1/download?format=...` 服务端完成 |
| 图片下载 | 直接 httpx GET 微信图床 URL |

## 三、可用 API 端点

| 端点 | 认证 | 用途 |
|------|------|------|
| `GET /api/public/v1/account?keyword=&begin=&size=` | 需要 | 搜索公众号 |
| `GET /api/public/v1/accountbyurl?url=` | 需要 | 按文章链接反查公众号 |
| `GET /api/public/v1/article?fakeid=&begin=&size=` | 需要 | 获取文章列表 |
| `GET /api/public/v1/authkey` | 需要 | 验证 Auth-Key |
| `GET /api/public/v1/download?url=&format=` | 不需要 | 下载文章内容 |
| `GET /api/public/beta/authorinfo?fakeid=` | 不需要 | 公众号主体信息 |
| `GET /api/public/beta/aboutbiz?fakeid=` | 不需要 | 公众号详细信息 |

## 六、使用方式

```bash
# 1. 确保 wechat-article-exporter 运行中
# 2. 编辑 config/wechat_config.py（设置 API 地址、Auth-Key、目标公众号）
# 3. 设置 base_config.py: PLATFORM = "wechat", CRAWLER_TYPE = "creator"
# 4. 运行
python main.py --platform wechat --type creator

# 或通过 CLI 参数覆盖配置
python main.py --platform wechat --type creator --creator_id "fakeid1,fakeid2"
python main.py --platform wechat --type search --keywords "公众号名称"
python main.py --platform wechat --type detail --specified_id "https://mp.weixin.qq.com/s/xxx"
```

## 七、注意事项

1. **Auth-Key 有效期约 4 天**，过期需重新登录 wechat-article-exporter 网站获取
2. **依赖 wechat-article-exporter 服务**持续运行，建议私有部署
3. **图片下载**需带 Referer 头（`https://mp.weixin.qq.com/`），部分为 webp 格式
4. **请求间隔**默认 2-3 秒，过快可能触发限流
5. **存储选项**支持全部 7 种后端: CSV / JSON / DB(MySQL) / PostgreSQL / SQLite / MongoDB / Excel
