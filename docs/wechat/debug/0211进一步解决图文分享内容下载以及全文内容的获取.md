# 问题解答

## 1. API字段说明

### 文章列表API的响应字段

通过 `/api/public/v1/article` 接口获取的文章列表**不包含文章全文内容**，只返回文章的元数据信息。主要字段包括： [1](#0-0) 

完整的响应字段示例： [2](#0-1) 

这些字段中：
- `title`: 文章标题
- `digest`: 文章摘要（非全文）
- `link`: 文章链接
- `cover`: 封面图片
- `author_name`: 作者名称
- `create_time`/`update_time`: 创建/更新时间
- `album_id`: 所属合集ID
- 等其他元数据字段

### 获取文章全文内容

要获取**文章的完整HTML内容**，需要使用 `/api/public/v1/download` 接口： [3](#0-2) 

该接口支持三种输出格式：
- `html`: 返回处理后的HTML全文
- `markdown`: 返回Markdown格式的全文
- `text`: 返回纯文本格式的全文

在系统内部下载文章时，完整的HTML内容会被存储，并且可以从中提取元数据（如阅读量、点赞数等）： [4](#0-3) 

## 2. 图文分享类内容图片下载解决方案

系统**已经实现**了对图文分享（特别是图片分享类型）内容的图片下载支持。处理流程如下：

### 图片分享文章的识别和处理

系统通过检测HTML中的 `#js_image_desc` 元素来识别图片分享类文章： [5](#0-4) 

### 图片提取和下载机制

对于图片分享文章，系统会：

1. **提取图片列表**：从HTML中的 `window.picture_page_info_list` 变量获取所有图片的CDN URL
2. **批量下载**：使用代理池系统并发下载所有图片
3. **替换路径**：将下载的图片保存到本地，并替换HTML中的图片引用路径

导出HTML文件时的处理： [6](#0-5) 

### 通用图片资源下载流程

对于所有类型的文章（包括图文分享），系统在导出时会：

1. **提取所有图片资源**（包括 `<img>` 标签的 `src` 和 `data-src` 属性）： [7](#0-6) 

2. **提取背景图片**： [8](#0-7) 

3. **并发下载资源**，支持重试和代理池管理： [9](#0-8) 

## Notes

- 文章列表API和文章内容下载API是两个独立的接口，前者只返回元数据，后者返回完整内容
- 图片分享类文章的图片下载功能已经内置在系统中，通过 `picture_page_info_list` 变量提取图片URL
- 系统使用代理池、并发下载、自动重试和缓存机制来确保图片下载的可靠性
- 所有下载的资源（包括图片）都会缓存在IndexedDB中以避免重复下载

export default defineEventHandler(async event => {
  const query = getQuery<SearchBizQuery>(event);
  if (!query.url) {
    return {
      base_resp: {
        ret: -1,
        err_msg: 'url不能为空',
      },
    };
  }

  const url = decodeURIComponent(query.url.trim());
  if (!urlIsValidMpArticle(url)) {
    return {
      base_resp: {
        ret: -1,
        err_msg: 'url不合法',
      },
    };
  }

  const format: string = (query.format || 'html').toLowerCase();
  if (!['html', 'markdown', 'text'].includes(format)) {
    return {
      base_resp: {
        ret: -1,
        err_msg: '不支持的format',
      },
    };
  }

  const rawHtml = await fetch(url, {
    headers: {
      Referer: 'https://mp.weixin.qq.com/',
      Origin: 'https://mp.weixin.qq.com',
      'User-Agent': USER_AGENT,
    },
  }).then(res => res.text());

  switch (format) {
    case 'html':
      return new Response(normalizeHtml(rawHtml, 'html'), {
        status: 200,
        headers: {
          'Content-Type': 'text/html; charset=UTF-8',
        },
      });
    case 'text':
      return new Response(normalizeHtml(rawHtml, 'text'), {
        status: 200,
        headers: {
          'Content-Type': 'text/plain; charset=UTF-8',
        },
      });
    case 'markdown':
      return new Response(new TurndownService().turndown(normalizeHtml(rawHtml, 'html')), {
        status: 200,
        headers: {
          'Content-Type': 'text/markdown; charset=UTF-8',
        },
      });
    default:
      throw new Error(`Unknown format ${format}`);
  }
});

  private async downloadResourceTask(url: string, fakeid: string): Promise<void> {
    this.pending.add(url);

    // 检查缓存是否可用，避免重复下载相同资源
    const cached = await getResourceCache(url);

    for (let attempt = 0; attempt < this.options.maxRetries; attempt++) {

        await updateResourceCache({

          url: url,
          file: blob,
        });
        this.pending.delete(url);
        this.completed.add(url);
        this.proxyManager.recordSuccess(proxy);
        return;
      } catch (error) {
        await this.handleDownloadFailure(proxy, url, attempt, error);
      }
    }

    this.pending.delete(url);
    this.failed.add(url);
