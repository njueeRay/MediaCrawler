微信公众号的 `item_show_type` 用于标识文章/素材类型，数字与中文标签的对应关系如下（来源：`config/index.ts` 的 `ITEM_SHOW_TYPE`） [1](#0-0) ：

| 数字 | 类型标签 |
|------|----------|
| 0    | 普通图文 |
| 5    | 视频分享 |
| 6    | 音乐分享 |
| 7    | 音频分享 |
| 8    | 图片分享 |
| 10   | 文本分享 |
| 11   | 文章分享 |
| 17   | 短文 |

在 API 爬取的数据结构中，该字段出现在：
- `AppMsgEx.item_show_type`（文章列表等通用结构） [2](#0-1) 
- `app_msg_item.item_show_type`（profile_ext_getmsg 接口返回） [3](#0-2) 
- 公共 API `/api/public/v1/article` 返回的文章对象中也包含 `item_show_type`（示例中为 0） [4](#0-3) 

在 UI 中，通过 `formatItemShowType` 将数字转为中文标签，例如文章列表页的“文章类型”列 [5](#0-4) 。

## Notes
- `item_show_type` 为数字类型，若出现未在 `ITEM_SHOW_TYPE` 中定义的值，`formatItemShowType` 会返回“未知类型”。
- 在导出 Excel 时，该列同样使用 `formatItemShowType` 进行格式化 [6](#0-5) 。
