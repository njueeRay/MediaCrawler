## 目标
导出 Excel 时包含作者/标题/正文等基础字段，并新增 `image_list`（文章图片链接列表）；支持配置开关决定是否下载图片到本地目录（按文章 ID 分目录）。

## 关键现状（可复用）
- Excel 导出主流程：`utils/download/Exporter.ts` -> `exportExcelFiles()`。
- 数据结构：`utils/exporter.ts` 中 `ExcelExportEntity`。
- 图片/资源提取：`utils/download/Exporter.ts` -> `extractResources()`（支持 `img[src]`、`img[data-src]`、背景图正则）。
- 资源下载：`utils/download/Exporter.ts` -> `downloadResourceTask()` + `writeFile()`。
- 导出设置 UI：`components/setting/Export.vue`，配置类型：`types/preferences.d.ts`。

## 实施步骤（按顺序）
### 1) 扩展导出数据结构
- 文件：`utils/exporter.ts`
- 变更：`ExcelExportEntity` 增加字段 `image_list?: string[]`。

### 2) 增加配置开关
- 文件：`types/preferences.d.ts`
- 变更：在 `ExportConfig` 增加 `exportExcelDownloadImages: boolean`（默认 `false`）。
- 文件：`components/setting/Export.vue`
- 变更：增加一个勾选框绑定 `preferences.exportConfig.exportExcelDownloadImages`。
- 文件：`composables/usePreferences.ts` 或初始化配置处（若存在默认值定义）
- 变更：给 `exportExcelDownloadImages` 设默认值 `false`。

### 3) 在 Excel 导出中填充 `image_list`
- 文件：`utils/download/Exporter.ts` -> `exportExcelFiles()`
- 变更：
	- 对每篇文章：读取缓存 HTML（已有 `getHtmlCache` 使用路径）或复用 `extractResources` 思路解析文章 HTML。
	- 提取 `img[src]` / `img[data-src]` / 背景图，得到 `resources: string[]`。
	- 写入 `exportedArticle.image_list = resources`。
- 注意：如果 HTML 缓存不存在，保持空数组并记录 warn 即可。

### 4) 可选：下载图片并替换为本地路径
- 触发条件：`preferences.value.exportConfig.exportExcelDownloadImages === true`。
- 文件：`utils/download/Exporter.ts`
- 变更：
	- 对 `exportedArticle.image_list` 逐条调用 `downloadResourceTask(url, article.fakeid)`。
	- 下载成功后，使用 `writeFile()` 写入 `images/${article.aid}/` 子目录。
	- 文件名可用 URL hash 或序号（避免非法字符）；建议保留扩展名。
	- 若需要离线使用，可把 `image_list` 中的 URL 替换为本地相对路径 `images/${aid}/xxx.ext`。

### 5) Excel 列定义补充
- 文件：`utils/exporter.ts` -> `export2ExcelFile()`
- 变更：新增列 `{ header: '图片列表', key: 'image_list', width: 50 }`。
- 写入格式：`image_list?.join(';')` 或 `join('\n')` 以便 Excel 中可读。

## 目录规划
- 导出目录：沿用现有 `exportDirName()` 逻辑。
- 图片目录：`<导出目录>/images/${article.aid}/`。

## 最小验收清单
- Excel 新列 `图片列表` 可见，且内容为链接列表或本地路径。
- 关闭下载开关时，仅导出链接，不创建图片文件。
- 开启下载开关时，图片保存到 `images/${aid}/`，Excel 中链接可选替换为本地路径。
