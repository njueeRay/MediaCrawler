## 四、未来 3 个版本路线图

```
现在         v1.3                v1.4                  v2.0
 │           │                   │                     │
 ▼           ▼                   ▼                     ▼
v1.2.0   ──→ 稳固核心          ──→ 能力扩展          ──→ 平台化
             清账 + 安全            并行 + UX             分布式 + 多租户
             3–4 周                 4–6 周                2–3 月
             ~2026-03-22            ~2026-05-10           2026-Q3
```

### v1.3「稳固核心」核心特性
1. 安全层 MVP：JWT + X-API-Key（S-01 · S-02 · W-01 · W-03）
2. Legacy 清除：`_run_task` 双路径合并（P-01），飞书双路径合并（F-01）
3. DB 基础设施：Alembic 唯一入口（I-01），abort_flags TTL（P-03），并发锁（P-04）
4. 订阅采集统一：SubscriptionCrawlManager 全面接管（P-09）
5. 日期过滤补全：B站/微博 env var（C-01 部分）

### v1.4「能力扩展」核心特性
1. CrawlerPool 多平台并行（C-02·C-03）+ MultiPlatformCrawlStep（P-06）
2. vue-flow Pipeline 可视化编辑器（W-02）
3. 执行历史实时日志 WebSocket（W-07）
4. 更多平台 DataFormatter（F-05），图片断点续传（F-04）
5. VitePress 文档站（D-01）

### v2.0「平台化」愿景
- User → Team → Workspace 三层组织模型
- Celery + Redis 替代 APScheduler，多机横向扩容
- Pipeline DAG 化（条件分支、fan-out/fan-in）
- 除飞书外支持 Notion / Google Sheets / Webhook
- OpenTelemetry + Prometheus + Grafana 可观测体系

**v2.0 Gate 条件**：v1.3+v1.4 P0/P1 全部交付；至少 1 名生产用户稳定运行 30 天无 P0 故障。
