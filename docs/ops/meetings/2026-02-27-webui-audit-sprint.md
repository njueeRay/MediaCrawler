**改动**:
- 连通性探测改为多端点策略（先 `/api/health`，后根路径），容错更强

**验证结果**: `POST /api/config/test {"type":"wechat"}` → `success: true, "微信源连接正常，认证有效"`

### Fix 2: 小红书创作者搜索（P1 → P0）

**文件**: `api/services/subscription_service.py`

**新增方法**:
- `_search_xhs(keyword)` — 主入口，三模式路由
- `_xhs_fetch_profile(user_id)` — URL/ID → 抓取主页 HTML → 解析 `__INITIAL_STATE__` 提取用户信息
- `_xhs_search_by_keyword(keyword)` — 关键词 → 搜索页 SSR → 提取笔记作者去重
- `_search_douyin(keyword)` — 抖音 URL/sec_uid 精确查找

**XHS 搜索支持模式**:
| 输入类型 | 示例 | 处理方式 |
|---------|------|---------|
| 主页 URL | `xiaohongshu.com/user/profile/xxx` | 解析 user_id → 抓取主页 |
| 用户 ID | `5b7a37b300000000070144ae` | 直接抓取主页 |
| 关键词 | `美食博主` | 搜索页 SSR → 笔记作者去重 |

**兜底策略**: 即使 XHS 反爬阻止了 HTML 解析，也返回含 user_id 的基础可订阅信息。

### Fix 3: 前端平台提示优化

**改动**:

## 三、关于"微信源认证无效"的分析

**结论**: 非代码 BUG。

| 验证点 | 结果 |
|--------|------|
| config 热重载是否覆盖 wechat_config | ✅ `reload_from_env()` 已包含全平台 reload |
| 连接测试 type 匹配 | ✅ `conn_type in ("wechat_source", "wechat")` 已正确 |
| 测试连接 + 认证验证 | ✅ 返回"连接正常，认证有效" |

用户看到的"认证信息无效"错误来自 wechat-article-exporter 远端服务真实返回的 `base_resp.ret != 0`。
可能原因：
1. auth key 已过期（有效期约 4 天，需在 wechat-article-exporter 重新登录获取）
2. wechat-article-exporter 服务端重启后 session 失效

**已增强**: 测试连接现在会明确提示 auth key 是否有效、是否可能过期。
